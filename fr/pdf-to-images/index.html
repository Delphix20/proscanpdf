PDF en images.
Enregistrez chaque page.

Transformez chaque page d’un PDF en un JPG distinct de haute qualité, puis enregistrez les images dans Photos ou partagez-les avec une autre app.

Un JPG par pageVers Photos, Fichiers ou une autre app.

Une image nette pour chaque page

ProScan PDF restitue toutes les pages dans leur ordre d’origine et crée un JPG haute qualité pour chacune. Un document multipage devient une série d’images numérotées.

Choisissez la destination

Enregistrez directement dans Photos ou ouvrez la feuille de partage iOS pour envoyer les images, les sauvegarder dans Fichiers ou poursuivre dans une app compatible.

Une conversion locale

Le PDF est rendu sur votre iPhone ou iPad. Il n’est pas transféré vers un serveur de conversion ProScan PDF.

Quand une image est préférable à un PDF

L’export est utile pour téléverser une page dans un formulaire, l’insérer dans une présentation, l’envoyer dans une messagerie ou conserver une copie visuelle dans Photos.

L’ordre des pages reste lisible

Chaque nom de fichier contient le numéro de page. Un PDF de cinq pages produit cinq JPG dans la même séquence, et non une seule image très longue.

Les fichiers temporaires sont supprimés

Les images sont préparées temporairement pour l’enregistrement ou le partage. Une fois l’opération terminée, ProScan PDF efface cet export afin de ne pas laisser de doublons cachés.

Les longs documents demandent plus de ressources

Chaque page doit être rendue comme une image complète. Un PDF long ou très graphique peut donc demander plus de temps et de mémoire temporaire. Les PDF protégés doivent être déverrouillés avant l’export. Le document source reste inchangé.

Questions fréquentes

À savoir
avant de commencer.

Les informations pratiques sur le fonctionnement de cet outil dans ProScan PDF.

Quel format d’image est créé ?

L’outil crée un fichier JPG haute qualité distinct pour chaque page du PDF.

Puis-je exporter un PDF multipage ?

Oui. Chaque page lisible est exportée dans l’ordre avec un nom de fichier numéroté.

Puis-je enregistrer ailleurs que dans Photos ?

Oui. Choisissez Partager ou enregistrer dans Fichiers pour sélectionner une destination dans la feuille de partage iOS.

Le PDF quitte-t-il mon appareil ?

Non. Le rendu des pages et la création des JPG s’effectuent localement.
