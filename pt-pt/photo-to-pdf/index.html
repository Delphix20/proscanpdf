Fotografias para PDF.
Um ficheiro organizado.

Escolha uma ou mais imagens e transforme-as num PDF mais fácil de arquivar, enviar e consultar do que um conjunto de fotografias separadas.

Uma ou várias fotografiasCrie um PDF partilhável no dispositivo.

Uma forma mais simples de enviar imagens

Reúna fotografias relacionadas num único PDF em vez de anexar cada imagem separadamente. É útil para notas fotografadas, registos, recibos, desenhos, páginas de referência e outros materiais visuais.

Um resultado com formato de documento

O PDF mantém cada imagem selecionada como uma página do mesmo ficheiro, facilitando mudar o nome, guardar, organizar e partilhar tudo a partir da mesma biblioteca Os meus ficheiros usada nas suas digitalizações.

Conversão privada

O processamento das fotografias e a criação do PDF acontecem no dispositivo. O ProScan PDF não precisa de enviar as imagens selecionadas para um servidor próprio para criar o ficheiro.

Um processo simples em três passos

Do ficheiro de origem ao
resultado final.

O ProScan PDF reúne a ação, a confirmação e o ficheiro guardado num processo simples.

01

Abra Fotografias para PDF

Aceda a Ferramentas e escolha Fotografias para PDF. O seletor do sistema permite escolher as imagens pretendidas sem conceder acesso desnecessário ao resto da biblioteca.

02

Selecione as fotografias de origem

Escolha uma fotografia para criar rapidamente um PDF de uma página ou selecione várias imagens relacionadas para um documento maior. O ProScan PDF prepara cada imagem como uma página sem distorcer as proporções.

03

Crie o PDF e continue em Os meus ficheiros

Guarde o resultado e continue a trabalhar em Os meus ficheiros. Pode mudar o nome, visualizar, organizar páginas, comprimir, adicionar uma marca de água, proteger com palavra-passe ou partilhar o PDF.

Detalhes úteis.
Limitações explicadas com clareza.

Útil para além da digitalização tradicional

Fotografias para PDF funciona muito bem quando o conteúdo já está na aplicação Fotografias: capturas de ecrã, formulários descarregados, notas manuscritas fotografadas, imagens de referência ou uma sequência de páginas capturadas anteriormente.

Todo o processo num só lugar

O PDF criado entra na mesma biblioteca dos ficheiros digitalizados. Não precisa de alternar entre um conversor de fotografias, um editor de PDF e outra aplicação de partilha apenas para concluir um documento.

Sem anúncios nem marca de água automática

A aplicação não interrompe a conversão com publicidade nem aplica a marca ProScan PDF ao resultado. Se quiser uma marca de água, a ferramenta específica permite escolher intencionalmente o texto e a cor.

Qualidade da imagem e tamanho do ficheiro

Fotografias de alta resolução podem gerar um PDF maior. Se o ficheiro final ficar demasiado grande para enviar ou guardar, utilize Comprimir PDF a seguir. A compressão funciona melhor em documentos baseados em imagens, como PDFs criados a partir de fotografias.

Perguntas frequentes

O que deve saber
antes de começar.

Informação prática sobre o funcionamento desta ferramenta no ProScan PDF.

Posso converter várias fotografias num único PDF?

Sim. Selecione várias fotografias e o ProScan PDF cria um PDF com várias páginas, utilizando uma imagem escolhida em cada página.

A aplicação estica as fotografias importadas?

Não. A conversão preserva as proporções da fotografia sem a forçar para um formato distorcido.

O ProScan PDF adiciona uma marca de água?

Não é adicionada qualquer marca de água automática. A ferramenta de marca de água só é utilizada quando decide aplicar uma.

Posso comprimir o PDF depois?

Sim. Abra Comprimir PDF em Ferramentas para reduzir o tamanho de PDFs baseados em imagens quando precisar de um ficheiro menor.
