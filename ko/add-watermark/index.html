문서 전체에 메시지 표시

기밀, 초안, 샘플 또는 프로젝트 이름 같은 텍스트를 입력하세요. ProScan PDF가 읽기 쉬운 반투명 효과로 모든 페이지 중앙에 대각선으로 배치합니다.

어울리는 색상 선택

시안, 흰색, 밝은 회색, 어두운 회색, 진한 빨간색, 진한 노란색, 검은색 중에서 선택할 수 있습니다. 기본값은 시안이며 PDF를 만들기 전에 선택을 분명하게 확인할 수 있습니다.

별도의 워터마크 사본

원본 PDF를 덮어쓰지 않습니다. ProScan PDF가 ‘내 파일’에 새 워터마크 파일을 만들어 수정되지 않은 원본도 그대로 사용할 수 있습니다.

02

03

워터마크 PDF 만들기를 실행하면 문서가 기기에서 처리되어 ‘내 파일’에 새 PDF로 저장됩니다. 완료 후 확인 메시지가 표시됩니다.

모든 페이지에 일관된 배치

워터마크 크기는 각 PDF 페이지에 맞춰지고 중앙에 대각선으로 배치됩니다. 세로, 가로, 혼합 크기 문서에서도 일관된 모양을 유지합니다.

초안과 제한된 공유에 유용

보이는 워터마크로 초안이나 샘플을 표시하고 내부 자료를 구분하거나 PDF를 보내기 전에 프로젝트 또는 조직 이름을 넣을 수 있습니다.

다른 PDF 도구와 연결

새 사본은 ‘내 파일’에 나타나며 ProScan PDF를 벗어나지 않고 이름 변경, 정리, 압축, 서명, 잠금, 공유를 계속할 수 있습니다.

편집 가능한 텍스트가 중요하면 원본을 보관하세요

워터마크를 일관되게 배치하기 위해 PDF를 페이지별로 다시 구성합니다. 선택 가능한 텍스트, 주석, 벡터 내용을 그대로 유지해야 한다면 원본을 보관하세요. 별도 사본으로 저장되므로 원본을 쉽게 남길 수 있습니다.

이 도구가 ProScan PDF에서 실제로 어떻게 작동하는지 알려드립니다.

워터마크가 모든 페이지에 들어가나요?

네. 선택한 텍스트와 색상이 새 PDF 사본의 모든 페이지에 적용됩니다.

어떤 색상을 사용할 수 있나요?

시안, 흰색, 밝은 회색, 어두운 회색, 진한 빨간색, 진한 노란색, 검은색을 사용할 수 있으며 기본값은 시안입니다.

원본 PDF가 바뀌나요?

아니요. 별도의 워터마크 사본을 ‘내 파일’에 저장합니다.

워터마크 처리를 위해 PDF가 업로드되나요?

아니요. 워터마크는 iPhone 또는 iPad에서 로컬로 렌더링됩니다.
