Ihre Kennzeichnung im Dokument

Geben Sie etwa VERTRAULICH, ENTWURF, MUSTER oder einen Projektnamen ein. Der Text wird gut lesbar, halbtransparent und diagonal über die Mitte jeder Seite gelegt.

Passende Farbe wählen

Zur Auswahl stehen Cyan, Weiß, Hellgrau, Dunkelgrau, Dunkelrot, Dunkelgelb und Schwarz. Cyan ist voreingestellt; die Auswahl bleibt vor der Erstellung sichtbar.

Separate Kopie statt Überschreiben

Die Quelldatei wird nicht unbemerkt ersetzt. ProScan PDF erstellt eine neue Datei mit Wasserzeichen in Meine Dateien und bewahrt das unveränderte Original.

Für echte Dokumente entwickelt

Nützliche Details.
Ehrliche Grenzen.

Einheitlich auf jeder Seite

Größe und Position des Wasserzeichens passen sich an die jeweilige Seite an. So entsteht auch bei Hochformat, Querformat oder gemischten Seitengrößen ein einheitlicher Eindruck.

Für Entwürfe und kontrollierte Weitergabe

Kennzeichnen Sie Entwürfe, Muster, interne Unterlagen oder Projektdokumente sichtbar, bevor Sie die PDF an andere Personen senden.

Teil des vollständigen PDF-Ablaufs

Die neue Kopie erscheint in Meine Dateien und kann anschließend umbenannt, verwaltet, komprimiert, signiert, geschützt oder geteilt werden.

Original behalten, wenn bearbeitbarer Text wichtig ist

Für eine gleichmäßige Platzierung wird die PDF Seite für Seite neu aufgebaut. Bewahren Sie das Original auf, wenn auswählbarer Text, Anmerkungen oder Vektorinhalte unverändert bleiben müssen. Die separate Kopie macht das einfach.

Häufige Fragen

Gut zu wissen,
bevor Sie starten.

Praktische Hinweise dazu, wie diese Funktion in ProScan PDF arbeitet.

Erscheint das Wasserzeichen auf jeder Seite?

Ja. Text und Farbe werden auf alle Seiten der neuen PDF-Kopie angewendet.

Welche Farben sind verfügbar?

Cyan, Weiß, Hellgrau, Dunkelgrau, Dunkelrot, Dunkelgelb und Schwarz. Cyan ist standardmäßig ausgewählt.

Wird meine ursprüngliche PDF ersetzt?

Nein. ProScan PDF speichert eine separate Kopie mit Wasserzeichen in Meine Dateien.

Wird die PDF zum Einfügen hochgeladen?

Nein. Das Wasserzeichen wird lokal auf Ihrem iPhone oder iPad gerendert.
