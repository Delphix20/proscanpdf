사진을 하나의 문서로

사진을 PDF로.
한 파일로 정리.

한 장 이상의 이미지를 선택해 따로 흩어진 사진보다 보관하고 보내고 다시 보기 쉬운 하나의 PDF로 만드세요.

여러 사진PDF 출력워터마크 없음기기 내 처리
한 장 또는 여러 장공유 가능한 PDF를 기기에서 만드세요.

이미지를 더 간편하게 전송

관련 사진을 하나씩 첨부하지 말고 한 PDF로 합치세요. 촬영한 메모, 기록, 영수증, 작품, 참고 페이지와 기타 이미지 자료에 유용합니다.

문서처럼 다루기 쉬운 결과

선택한 각 이미지는 하나의 PDF 안에서 개별 페이지가 됩니다. 스캔 문서와 같은 ‘내 파일’ 보관함에서 이름을 바꾸고 저장하고 정리하고 공유하기 쉽습니다.

비공개 변환

사진 처리와 PDF 생성은 기기에서 이루어집니다. 파일을 만들기 위해 선택한 이미지를 ProScan PDF 서버에 업로드할 필요가 없습니다.

간단한 3단계 작업

원본 파일에서
완성된 결과까지.

ProScan PDF는 처리, 확인, 저장을 하나의 명확한 흐름으로 연결합니다.

01

‘사진을 PDF로’ 열기

‘도구’에서 ‘사진을 PDF로’를 선택하세요. 시스템 사진 선택기를 사용하면 전체 보관함에 불필요한 접근 권한을 주지 않고 포함할 이미지만 선택할 수 있습니다.

02

원본 사진 선택

빠른 1페이지 PDF에는 사진 한 장을, 긴 문서에는 관련 이미지 여러 장을 선택하세요. ProScan PDF는 비율을 늘이거나 찌그러뜨리지 않고 각 이미지를 PDF 페이지로 준비합니다.

03

만든 뒤 ‘내 파일’에서 계속 작업

결과를 저장한 뒤 ‘내 파일’에서 이름 변경, 보기, 페이지 정리, 압축, 워터마크 추가, 암호 잠금, 공유를 할 수 있습니다.

명확한 한계.

일반 스캔 외에도 유용

자료가 이미 사진 보관함에 있을 때도 좋습니다. 스크린샷, 내려받은 양식, 손글씨 메모 사진, 참고 이미지, 이전에 촬영한 여러 페이지를 하나로 만들 수 있습니다.

한곳에서 끝나는 작업 흐름

생성된 PDF는 스캔 파일과 같은 문서 보관함에 추가됩니다. 문서 하나를 완성하려고 사진 변환기, PDF 편집기, 공유 앱을 오갈 필요가 없습니다.

광고 및 자동 워터마크 없음

변환 중 광고로 방해받지 않으며 결과에 ProScan PDF 워터마크가 자동으로 들어가지 않습니다. 워터마크가 필요할 때만 별도의 ‘워터마크 추가’ 도구에서 텍스트와 색상을 선택하세요.

이미지 품질과 파일 크기

고해상도 사진은 더 큰 PDF를 만들 수 있습니다. 완성된 파일이 이메일이나 저장 공간에 너무 크다면 이후 ‘PDF 압축’을 사용하세요. 사진으로 만든 PDF와 같은 이미지 기반 문서에서 가장 효과적입니다.

자주 묻는 질문

시작하기 전에
알아둘 내용.

이 도구가 ProScan PDF에서 실제로 어떻게 작동하는지 알려드립니다.

여러 사진을 하나의 PDF로 만들 수 있나요?

네. 여러 사진을 선택하면 각 이미지를 한 페이지씩 담은 다중 페이지 PDF를 만듭니다.

가져온 사진이 늘어나거나 찌그러지나요?

아니요. 사진을 왜곡된 모양에 강제로 맞추지 않고 원본 비율을 유지합니다.

ProScan PDF 워터마크가 추가되나요?

자동 워터마크는 추가되지 않습니다. 직접 적용하려는 경우에만 별도의 워터마크 도구를 사용합니다.

나중에 PDF를 압축할 수 있나요?

네. 더 작은 파일이 필요하면 ‘도구’에서 ‘PDF 압축’을 열어 이미지 기반 PDF의 크기를 줄이세요.

PDF로 스캔. 선명한 페이지로.

용도에 맞춘 8가지 스캔 모드, 실용적인 페이지 설정, 익숙한 Apple 촬영 화면으로 종이 문서를 깔끔한 PDF로 만드세요.

PDF를 이미지로. 페이지별로 저장.

PDF의 각 페이지를 별도의 고화질 JPG로 만든 뒤 사진 보관함에 저장하거나 다른 앱으로 공유할 수 있습니다.

PDF 압축. 차이를 한눈에.

스캔되었거나 이미지가 많은 PDF의 크기를 기기에서 줄이고 새 파일이 준비되면 전후 결과를 명확하게 확인하세요.

PDF 페이지 정리. 필요한 부분만.

페이지 추출, 순서 변경, 삽입, 삭제와 여러 PDF 병합을 한 문서 보관함에서 처리하고 수정된 사본을 저장하세요.
