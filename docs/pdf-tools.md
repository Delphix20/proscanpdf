# ProScan PDF tool reference

This page is a machine-readable reference for the PDF tools available in ProScan PDF on iPhone and iPad.

| Tool | Input | Output | Processing | Important limitation |
| --- | --- | --- | --- | --- |
| Photos to PDF | One or more photos | Multi-page PDF | On device | High-resolution photos can create a large PDF |
| PDF to Images | PDF | Page images | On device | Large documents can take longer and use more memory |
| Add Watermark | PDF and watermark text/color | New watermarked PDF | On device | Creates a new copy rather than changing the source silently |
| Compress PDF | Scanned or image-based PDF | New compressed PDF | On device | Vector-heavy PDFs may show only a modest reduction |
| ID Photo Maker | Camera or imported portrait | JPEG, PNG or printable PDF sheet | On device | Government acceptance is not guaranteed; official requirements must be checked |
| Extract Pages | PDF and selected pages | New PDF | On device | Keep the original until the extracted result is verified |
| Organize Pages | PDF | Modified PDF | On device | Reorder, insert and delete should be reviewed before replacing an archival workflow |
| Merge PDFs | Two or more PDFs | Combined PDF | On device | The selected document order determines the merged result |
| PDF to Word | PDF | Editable DOCX | On device | Complex tables, fonts and layouts may require manual cleanup |
| Search PDF | PDF | Searchable PDF copy | On device | OCR accuracy depends on source quality |
| OCR | Camera image or document | Editable recognized text | On device | Important names and numbers should be reviewed |
| Sign PDF | PDF, signature or text box | Modified PDF | On device | This is a document signature tool, not a remote identity-verification service |
| Lock PDF | PDF and password | Password-protected PDF | On device | The password should be sent separately from the file |

## Completion feedback

ProScan PDF displays a confirmation after save, extraction, page modification, watermarking, signing, locking, OCR export and other document operations. PDF compression uses a larger result card that reports original size, compressed size and percentage reduction.

## File availability

The primary working copy is kept locally for fast opening and preview generation. When iCloud is available, a private backup copy can be maintained for recovery on another Apple device. iCloud behavior depends on the user's Apple account, storage, settings and network connection.
