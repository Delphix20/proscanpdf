Gesicht im richtigen Verhältnis

Die automatische Erkennung hilft, Kopf und Gesicht passend im gewählten Seitenverhältnis zu positionieren. Der Ausschnitt kann anschließend manuell feinjustiert werden.

Foto aufnehmen oder auswählen

Verwenden Sie die Kamera für ein neues Bild oder importieren Sie ein vorhandenes Foto. Die ursprünglichen Proportionen bleiben dabei erhalten und werden nicht gestreckt.

Einzelbild oder druckbarer Bogen

Exportieren Sie ein einzelnes Foto oder ordnen Sie mehrere Exemplare auf einem Druckbogen an, um sie zu Hause oder bei einem Fotodienst auszudrucken.

Von der Vorlage zum
fertigen Ergebnis.

Aktion, Bestätigung und gespeicherte Datei bleiben in einem übersichtlichen Arbeitsablauf innerhalb von ProScan PDF.

Foto aufnehmen oder importieren

Öffnen Sie Passfoto erstellen und wählen Sie Kamera oder Fotos. Nutzen Sie eine scharfe Aufnahme mit gleichmäßiger Beleuchtung und ruhigem Hintergrund.

02

Format und Ausschnitt anpassen

Erstellen Sie das Passfoto als Einzelbild oder Druckbogen und speichern oder teilen Sie das Ergebnis über die angebotenen Ziele.

Für echte Dokumente entwickelt

Nützliche Details.
Ehrliche Grenzen.

Mehrere gebräuchliche Größen

Vorlagen für verbreitete Pass-, Visa- und Ausweisformate erleichtern den Start. Eigene Maße helfen, wenn eine Behörde oder Organisation ein abweichendes Format verlangt.

Qualitätshinweise vor dem Export

Die App kann auf einen ungeeigneten Ausschnitt oder eine zu geringe Auflösung hinweisen. So lassen sich offensichtliche Probleme vor dem Drucken erkennen.

Private Bildverarbeitung

Gesichtserkennung, Zuschnitt und Ausgabe erfolgen direkt auf dem Gerät. Das Porträt wird nicht an einen ProScan-PDF-Server übertragen.

Offizielle Anforderungen immer prüfen

Fotoformat, Kopfposition, Hintergrund, Gesichtsausdruck und weitere Vorgaben unterscheiden sich je nach Land und Dokument. Die App unterstützt bei Größe und Zuschnitt, ersetzt aber keine Prüfung der aktuell gültigen behördlichen Anforderungen.

Häufige Fragen

Gut zu wissen,
bevor Sie starten.

Praktische Hinweise dazu, wie diese Funktion in ProScan PDF arbeitet.

Kann ich ein vorhandenes Foto verwenden?

Ja. Sie können ein Bild aus Fotos wählen oder direkt ein neues aufnehmen.

Wird das Foto beim Aufnehmen gestreckt?

Nein. Die Proportionen des aufgenommenen oder importierten Bildes bleiben erhalten.

Kann ich mehrere Passfotos auf einer Seite anordnen?

Ja. Sie können einen druckbaren Bogen mit mehreren Exemplaren erstellen.

Garantiert die App die Annahme durch jede Behörde?

Nein. Prüfen Sie vor dem Einreichen immer die aktuellen offiziellen Vorgaben für das konkrete Dokument.
