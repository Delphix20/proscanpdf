Limiti trasparenti.

Quando ti serve un’immagine invece di un PDF

L’esportazione è utile per caricare una pagina in un modulo, inserirla in una presentazione, inviarla tramite messaggistica o conservarne una copia visiva in Foto.

L’ordine resta sempre chiaro

Ogni nome di file include il numero di pagina. Un PDF di cinque pagine crea cinque JPG nella stessa sequenza, non un’unica immagine molto lunga.

I file temporanei vengono rimossi

Le immagini vengono preparate temporaneamente per il salvataggio o la condivisione. Al termine, ProScan PDF elimina l’esportazione temporanea per evitare duplicati nascosti.

I documenti grandi richiedono più risorse

Ogni pagina deve essere elaborata come immagine completa. Un PDF lungo o ricco di grafica può richiedere più tempo e memoria temporanea. I PDF protetti devono essere sbloccati prima dell’esportazione. Il file di origine non viene modificato.

prima di iniziare.

Informazioni pratiche su come funziona questo strumento in ProScan PDF.

Quale formato di immagine crea lo strumento?

Crea un file JPG separato di alta qualità per ogni pagina del PDF.

Posso esportare un PDF multipagina?

Sì. Ogni pagina leggibile viene esportata in ordine con un nome numerato.

Posso salvare le immagini fuori da Foto?

Sì. Scegli Condividi o salva in File e seleziona una destinazione nel foglio di condivisione di iOS.

Il PDF lascia il mio dispositivo?

No. L’elaborazione e la creazione dei JPG avvengono localmente.
