Una firma donde corresponde

Abre las herramientas de formulario y añade una firma directamente en la página adecuada. La firma pasa a formar parte del documento en lugar de enviarse como imagen aparte.

Completa campos sencillos

Añade un campo de texto para nombres, fechas, respuestas breves u otra información que deba aparecer sobre la página existente.

Protege archivos sensibles

Crea una copia protegida con contraseña antes de enviar documentación confidencial. La protección se aplica localmente en el dispositivo.

Un proceso claro en tres pasos

Del archivo original al
resultado final.

ProScan PDF mantiene la acción, la confirmación y el archivo guardado dentro de un mismo proceso sencillo.

01

Abre el PDF que quieres completar

Selecciona el documento en Mis archivos y abre los controles de formulario. La página permanece visible mientras añades texto o una firma.

02

Coloca el elemento

Elige Añadir campo de texto o Añadir firma, colócalo en la página correspondiente y revisa el resultado antes de guardar.

03

Protege o comparte la copia

Cuando esté listo, usa Proteger para crear una versión con contraseña o Compartir para abrir la hoja de compartir de iOS.

Pensado para documentos reales

Detalles útiles.
Límites transparentes.

Un proceso de firma práctico

Completa documentos cotidianos sin imprimirlos, firmarlos y volver a escanearlos. Las firmas y los campos de texto forman parte del mismo flujo PDF.

La contraseña es una decisión explícita

No todos los archivos necesitan cifrado. Tú decides cuándo un PDF debe exigir una contraseña, sin protección aplicada de forma inesperada.

Confirmación clara al guardar

Una tarjeta confirma que el PDF modificado o firmado se ha guardado. La biblioteca y la vista previa se actualizan para mostrar la versión nueva.

Envía la contraseña por separado

Un PDF protegido solo es tan seguro como su contraseña. Para contenido sensible, utiliza una contraseña sólida y envíala por un canal diferente al documento.

Preguntas frecuentes

Lo que debes saber
antes de empezar.

Información práctica sobre el funcionamiento de esta herramienta en ProScan PDF.

¿Puedo añadir texto y una firma?

Sí. Las herramientas de formulario permiten añadir campos de texto y firmas al PDF.

¿Puedo proteger un PDF con contraseña?

Sí. La acción Proteger crea una copia protegida localmente.

¿Cómo envío el documento terminado?

Usa Compartir para abrir la hoja de compartir de iOS y elegir un destino.

¿La firma sube el PDF a un servidor?

No. La edición y la firma se realizan en tu dispositivo.
