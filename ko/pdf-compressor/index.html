별도의 압축 사본

ProScan PDF는 처리, 확인, 저장을 하나의 명확한 흐름으로 연결합니다.

01

PDF 선택

‘도구’에서 ‘PDF 압축’을 탭하고 보관함에서 문서를 선택하세요. 이미지가 많은 스캔은 압축할 데이터가 많아 가장 좋은 후보입니다.

02

앱에서 페이지 다시 구성

문서를 읽고 공유하기에 실용적인 상태로 유지하면서 저장 크기를 줄이도록 페이지를 기기에서 렌더링하고 인코딩합니다.

03

절감 결과 확인

처리가 끝나면 결과 카드가 원본과 압축된 크기를 비교하고 절감률을 보여 줍니다. 새 PDF는 ‘내 파일’에서 사용할 수 있습니다.

이메일과 공유 전에 유용

작은 PDF는 이메일 첨부, 양식 업로드, 장기 보관이 더 쉽습니다. 많은 스캔 문서가 기기나 iCloud 저장 공간을 차지할 때도 도움이 됩니다.

방향과 페이지 순서 유지

페이지 순서를 바꾸거나 내용을 반전하지 않고 PDF를 다시 구성합니다. 완성된 문서는 원본과 같은 읽기 방향과 페이지 순서를 유지합니다.

PDF 작업을 계속 진행

압축 후 새 사본을 보고 이름을 바꾸고 정리하고 워터마크를 추가하고 서명하고 잠그고 공유할 수 있습니다. 결과는 임시 위치가 아니라 같은 보관함에 남습니다.

압축 효과가 좋은 문서

압축은 스캔 및 이미지 기반 PDF에 최적화되어 있습니다. 효율적인 벡터 텍스트가 대부분인 문서는 이미 작아 절감폭이 적을 수 있습니다. 다시 렌더링하면 매우 미세한 이미지가 조금 부드러워질 수 있으므로 보관 품질이 중요할 때는 원본을 유지하세요.

이 도구가 ProScan PDF에서 실제로 어떻게 작동하는지 알려드립니다.

압축하면 원본 PDF를 덮어쓰나요?

아니요. 별도의 압축 사본을 저장하므로 원본을 계속 사용할 수 있습니다.

어떤 PDF가 가장 많이 줄어드나요?

스캔 페이지, 사진, 기타 이미지가 많은 PDF가 일반적으로 가장 크게 줄어듭니다.

얼마나 공간을 절약했는지 볼 수 있나요?

네. 성공 카드에 원본 크기, 압축된 크기, 절감률이 표시됩니다.

압축에 외부 서버가 필요한가요?

아니요. 문서는 iPhone 또는 iPad에서 로컬로 처리됩니다.
