# ProScan PDF privacy and document processing

## Summary

ProScan PDF is designed around local document processing. Scanning, OCR, PDF creation, page organization, conversion, watermarking, compression, signing, password protection and ID photo preparation run on the user's iPhone or iPad.

ProScan PDF does not operate a document-processing server and does not upload user documents to the developer's servers.

## Local storage

The app stores its primary working copies in the local ProScan PDF library. Local copies are intended to make files and document previews available quickly without waiting for an iCloud download each time the user opens My Files.

Documents remain subject to normal iOS storage behavior, device backups, available space and actions taken by the user inside the app.

## iCloud backup

When iCloud is available and enabled for the app, ProScan PDF can create private backup copies in the user's iCloud account. This is an Apple service between the user and Apple; it is not a ProScan PDF server.

iCloud backup availability depends on:

- the user being signed into iCloud;
- iCloud Drive being enabled;
- sufficient iCloud storage;
- network availability;
- Apple's synchronization state and device storage management.

## Offline behavior

Core capture, OCR and PDF tools can work without an internet connection. The following actions require connectivity when used:

- creating or updating an iCloud backup;
- sending a document through an online sharing destination;
- opening external websites or App Store pages;
- downloading an iCloud-only backup after reinstalling or moving to another device.

## Analytics on the website

The ProScan PDF website asks for permission before loading optional Google Analytics. If analytics are declined, the analytics script is not loaded. The website does not use advertising cookies.

## Important distinction

Local processing does not make every workflow risk-free. Users remain responsible for choosing strong PDF passwords, checking OCR output, confirming official ID-photo requirements and selecting an appropriate sharing destination.
