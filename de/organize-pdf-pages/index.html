Dokument Seite für Seite sehen

Seiten verwalten zeigt visuelle Vorschauen, damit Sie die richtige Seite erkennen, ohne nur nach Nummern zu raten. Ausgewählte Seiten werden deutlich hervorgehoben.

Gezielte PDF erstellen

Wählen Sie nur die relevanten Seiten und speichern Sie sie als neues Dokument. Das Original bleibt erhalten, während die kürzere PDF in Meine Dateien erscheint.

Bestehende Datei neu strukturieren

Ordnen Sie Seiten neu an, fügen Sie Inhalte aus einer anderen Quelle ein oder entfernen Sie unnötige Seiten. Speichern Sie die geänderte PDF, sobald die Reihenfolge stimmt.

Ein klarer Ablauf in drei Schritten

Von der Vorlage zum
fertigen Ergebnis.

Aktion, Bestätigung und gespeicherte Datei bleiben in einem übersichtlichen Arbeitsablauf innerhalb von ProScan PDF.

01

Seiten verwalten öffnen

Wählen Sie unter Meine Dateien eine PDF und tippen Sie auf Verwalten. Die Seiten erscheinen als Vorschauen mit den Aktionen Extrahieren, Anordnen, Einfügen und Löschen.

02

Seiten oder Aktion auswählen

Markieren Sie Seiten zum Extrahieren oder Löschen, ziehen Sie sie beim Anordnen an die gewünschte Position oder fügen Sie zusätzliche Inhalte ein. Die aktive Aktion bleibt sichtbar.

03

Passendes Ergebnis speichern

Speichern Sie extrahierte Seiten als neue PDF oder sichern Sie das geänderte Dokument nach Anordnen, Einfügen oder Löschen. Eine Abschlusskarte bestätigt die erfolgreiche Erstellung.

Nützliche Details.
Ehrliche Grenzen.

Nur benötigte Seiten weitergeben

Wenn nur ein Teil des Dokuments wichtig ist, erstellen Sie daraus eine kompakte PDF. Das eignet sich für einzelne Vertragsseiten, ein Kapitel, einen Beleg in einem großen Scan oder ausgewählte Berichtsseiten.

PDFs aus Meine Dateien zusammenführen

Im Auswahlmodus können Sie mehrere PDF-Dateien zu einem neuen Dokument verbinden – ohne Upload zu einem externen Dienst und ohne anschließenden Download.

Direkte Rückmeldung in der Bibliothek

Gelöschte Karten blenden weich aus, während die verbleibenden Dateien kontrolliert nachrücken. Zusammengefasste Aktualisierungen verhindern doppelte Bewegungen nach einem Vorgang.

Originale wichtiger Dokumente aufbewahren

Die Seitenbearbeitung erstellt klare geänderte oder extrahierte Ergebnisse. Bei rechtlichen, finanziellen oder archivwürdigen Dokumenten sollten Sie das unveränderte Original dennoch behalten, bis Sie jede Seite der neuen Datei geprüft haben.

Häufige Fragen

Gut zu wissen,
bevor Sie starten.

Praktische Hinweise dazu, wie diese Funktion in ProScan PDF arbeitet.

Kann ich nur ausgewählte Seiten extrahieren?

Ja. Markieren Sie die gewünschten Seiten und speichern Sie sie als neue PDF.

Kann ich die Seitenreihenfolge ändern?

Ja. Wählen Sie Anordnen, verschieben Sie die Vorschauen und speichern Sie die geänderte PDF.

Kann ich mehrere PDFs zusammenführen?

Ja. Wählen Sie unter Meine Dateien mehrere PDFs aus und tippen Sie auf Zusammenführen.

Müssen Dokumente dafür hochgeladen werden?

Nein. Extrahieren, Anordnen, Einfügen, Löschen und Zusammenführen erfolgen lokal.
